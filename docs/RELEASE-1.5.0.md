# Fedexe API 1.5.0

- Importe coleções e ambientes de um workspace do Postman diretamente pelo app Windows. Importe o conjunto completo ou escolha itens individuais.
- A chave de API fica no Gerenciador de Credenciais do Windows. O relatório reúne itens importados, falhas e ajustes manuais.
- A conversão reaproveita as regras de importação do Fedexe para pastas, requisições, ambientes e validações compatíveis. A importação de OpenAPI está prevista para a 1.7.

Abra **Importar → Importar workspace do Postman** para começar.
