## Fedexe API 1.2.0

- O Fedexe abre em inglês quando o perfil ainda não tem preferência de idioma. Para mudar, abra **Settings → Interface language** e selecione **Português (Brasil)**. A escolha fica salva no dispositivo.
- Menus, editor, runner, diálogos e mensagens do app acompanham o idioma escolhido, assim como a formatação de datas e números. Os nomes e textos salvos nas suas coleções são preservados.

**Windows x64.** Na 1.1.0, abra **Configurações → Atualizações** para instalar a nova versão. Se estiver na série 1.0.x, baixe o instalador `Fedexe.API_1.2.0_x64-setup.exe` abaixo e execute-o sobre a instalação atual.
