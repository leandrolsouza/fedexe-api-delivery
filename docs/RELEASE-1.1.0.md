# Fedexe API 1.1.0

O Fedexe agora verifica se há uma versão estável para Windows quando você abre o app. Também é possível verificar em **Configurações → Atualizações**. Quando houver uma atualização, escolha instalar ou adiar. O Fedexe verifica a assinatura antes de executar o instalador.

**Se você usa a 1.0.x**, baixe o instalador Windows x64 anexado a esta release e execute-o sobre sua instalação atual. A 1.0.x ainda não tem atualizador. A instalação mantém o workspace e os segredos no cofre de credenciais do Windows.
