• OAuth 2.0 no desktop: autentique com Authorization Code e PKCE no navegador padrão do Windows. O Fedexe mantém a sessão no Gerenciador de Credenciais do Windows e renova tokens quando o provedor oferece refresh token.
• Client Credentials no desktop e na CLI: configure o provedor no editor de autorização e use variáveis de ambiente para fornecer o Client secret em CI.
• Exporte coleções com a configuração OAuth. Os tokens e valores de Client secret ficam fora dos arquivos exportados e dos relatórios do runner.
