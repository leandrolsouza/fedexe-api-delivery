## Fedexe API 1.3.0

A 1.3.0 adiciona um runner de coleções para CI no Windows x64. A CLI executa coleções ou pastas exportadas com o mesmo executor HTTP do desktop. Ela aceita um ambiente explícito e segredos por variáveis de processo, reaproveita valores extraídos entre requisições e gera relatórios JSON. Os códigos de saída distinguem sucesso, falha de validação e erro de execução ou configuração.

### Downloads para Windows x64

- **Desktop** — `Fedexe.API_1.3.0_x64-setup.exe`. Quem já usa o atualizador do Fedexe pode atualizar pelo aplicativo.
- **CLI** — `Fedexe.API_1.3.0_cli_windows-x64.zip`. Extraia os arquivos na mesma pasta e execute `node fedexe.mjs --help` usando Node.js 22 ou superior. O pacote inclui o guia com exemplo de GitHub Actions.

Cada download acompanha um arquivo SHA-256. O instalador inclui a assinatura usada pelo atualizador do Fedexe.
